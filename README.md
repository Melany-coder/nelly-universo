# El universo de nuestro amor

Un mini sitio hecho para **Nelly Sofia**: musicales e ideas de playlists por actos,
su biblioteca de historias, el jardín tierno (mariposas, conejitos, Snorlax, Gengar,
colores), sus animes y dramas favoritos, y una carta final.

## Páginas

| Archivo | Qué es |
| --- | --- |
| `index.html` | Página principal (copia de `nelly-universo.html`, para que GitHub Pages abra el sitio en la raíz) |
| `nelly-universo.html` | Página principal original |
| `historias-nelly.html` | La autora de universos: ideas de libros, personajes y frases |

## Estructura

- HTML, CSS y JS en un solo archivo por página: no hay build, no hay dependencias.
- Las imágenes son externas (Peakpx, Windows Spotlight Images, Fleur Harris, Rawpng),
  así que el sitio necesita internet para verse completo.
- Cada página hija tiene un enlace "← Volver al universo" hacia `nelly-universo.html`.

## Editar

Abrir el `.html` en cualquier editor de texto, escribir dentro de los bloques de
contenido y guardar. Para verlo: doble clic en el archivo, o `python3 -m http.server`
dentro de la carpeta.

## Publicar

El sitio está pensado para GitHub Pages: el repo ya publica `index.html` desde la
rama `main`.

Hecho con colores lila, rosa y mucho amor.
